# AI Tools Directory

Starter project for an AI tools directory built with Next.js, React, TypeScript, Tailwind CSS, Supabase, and SQL.

## Getting started

```bash
npm install
npm run dev
```

Copy `.env.example` to `.env.local` and add the Supabase project URL and publishable key before connecting the app to Supabase.

The initial database schema is in `supabase/schema.sql`.
